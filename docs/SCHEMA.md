# Stable interface v1

Ownership: A integrates schema/model/trainer. B owns external adapters and writes independent caches/runs. Propose changes in TASKS.md before changing dimensions.

Prepared shards are numeric/string NPZ (no pickle). Node features `x`: N x 31 float32 (21 amino-acid identities, three density counts, CA bend, three CA-to-backbone distances, three backbone-atom masks). Distances/normalizations are invariant under rotation/translation. Coordinates use Angstrom. `edges`: 2 x E int64 undirected i<j; `edge_attr`: E x 4, distance/16, exp(-distance/8), clipped polymer separation/100, neighbor flag. Candidate edges use apo only: 12 A radius, nearest 16 within 16 A, sequence separation <=2; spatial degree capped at 48 plus sequence edges. No holo neighbors are inserted.

`ApoInput` contains x, coords, edges, edge_attr, residue_ids, resolved sequence only. Targets are stored separately: `y` N official union pocket labels for selected apo chain, `contact_y` E x 2 formation/breakage, `contact_mask` E. Official negatives are incompletely annotated background. Contact: C-beta <8 A, C-alpha for glycine, excluding polymer sequence neighbors <=2 in either endpoint. Global sequence alignment masks mismatches/unknowns/unresolved atoms. A pair with <80% valid matched residues is excluded from the initial debug pipeline.

mmCIF author chain/residue/insertion IDs are preserved. Polymer label_seq_id handles gaps and insertion codes for sequence-neighbor masking. PDB inference fallback uses author residue numbers, so mmCIF is preferred for insertion-heavy inputs. First structural model only; standard ATOM polymer residues with CA only; nonstandard polymer residues excluded. Alternate atom location selected by highest occupancy then lexical ID. Missing backbone atoms are masked. Single-chain context is a declared approximation; surrounding chains/cofactors are retained in raw files but not geometry inputs. Exact curated holo ligand chain/name/number must resolve uniquely. Official labels are used, not a newly invented ligand distance label.

Optional frozen feature interface: `if_features` N x 23 = native NLL, entropy, 21 probabilities; `if_mask` N x 1. Optional energy interface: `energy` N x 3; `energy_mask` N x 1. All float32; disabled in initial configs. An enabled branch without available features fails training. Missing energy is zero-masked after adaptation. Cache keys must include apo hash, preprocessing version, feature checkpoint hash and settings. No paired/holo feature differences are inference inputs.

Outputs: N pocket probabilities, E x 2 contact probabilities, N x K region assignments, residue IDs and apo coordinates. Only candidate contact probabilities are predicted; their formation recall ceiling is recorded. Regions are not experimentally established domains; predictions are not a realized conformation or physical opening probability.

Loss: pocket BCE with train-only positive weight capped 50; contact BCE with two train-only positive weights capped 100, weight 0.25; region coherence squared assignment difference 0.01, KL(mean assignment || uniform) 0.01, mean assignment entropy 0.001. Initial losses and geometry are float32. Train-only mean/std (std floor .05) normalize node features.

Primary metric: arithmetic mean of per-protein sklearn average precision on observed residue labels. No-positive proteins are excluded from macro AP and recorded as null. Pooled AP is separate; AUROC is null for one-class proteins; recall budget is ceil(0.1*N). Contact AP reported separately. Bootstrap samples proteins 2,000 times with fixed seed; this is not family-independent uncertainty. Pocket-level localization and family-stratified metrics remain pending.

Executed energy features: log1p heavy-atom clash count, log1p mean OpenMM force magnitude, reserved zero; validity mask. Potentials are whole-system report fields only. Ordinary concatenation is implemented separately from bounded adaptation. Diagnostic IF permutation and energy-value-zeroing use identical deterministic controls in train/evaluation. Apo-only inference caches versioned geometry plus checkpoint/settings-keyed IF; energy cache includes adapter hash/OpenMM version.
